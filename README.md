# Emojis

Mod de cliente para Minecraft Java **1.21.11** con Fabric, creado por
**vanlishedz**.

## Descarga e instalación

Descarga el JAR oficial más reciente desde la pestaña **Releases** de este
repositorio. Instala Fabric Loader para Minecraft 1.21.11 y Fabric API; luego
copia `emojis-<version>.jar` a la carpeta `mods` de tu instancia.

Abre el chat y pulsa el icono **☺** junto al campo de texto o usa F9 para abrir
el selector. Para instrucciones de uso y ayuda, consulta este README y las
notas de la release. Al informar un error, indica la versión del mod,
Minecraft, Fabric Loader, otros mods relevantes y pasos para reproducirlo. No
adjuntes tokens, contraseñas ni datos personales.

## Integridad

En cada release se publicará el SHA-256 del JAR. Comprueba que el archivo
descargado coincide antes de instalarlo.
